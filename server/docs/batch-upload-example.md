# 批量上传房源示例

接口：
- `POST /api/house/batchUpload`

表单参数：
- `file`：Excel 文件
- `remark`：可选，批量上传备注，会记录到批次记录中

示例文件：
- [house-batch-upload-example.xlsx](/Users/xiongda/GolandProjects/zhaofang/server/docs/house-batch-upload-example.xlsx)

## 表头说明

系统当前支持以下表头名：

- `楼盘名称`
- `小区名称`
- `楼栋房间号`
- `户室号`
- `房间号`
- `价格`
- `返佣金额`
- `备注`
- `标签`
- `出租类型`
- `房屋类型`
- `房间类型`

其中：
- `楼盘名称` 和 `小区名称` 二选一即可
- `楼栋房间号` 和 `户室号` 二选一即可
- `房屋类型` 和 `房间类型` 二选一即可

## 推荐模板列

建议直接使用下面这 8 列：

1. `楼盘名称`
2. `楼栋房间号`
3. `房间号`
4. `价格`
5. `返佣金额`
6. `备注`
7. `标签`
8. `出租类型`
9. `房屋类型`

## 示例值说明

- `出租类型`
  - `整租`
  - `分整租`
  - `合租`
  - `房东房源`

- `房屋类型`
  - `1居`
  - `2居`
  - `3居`
  - `4居+`
  - `开间`
  - `主卧`
  - `次卧`
  - `暗间`
  - `房东房源`

- `标签`
  - 多个标签直接用中文逗号拼接即可
  - 示例：`可短租,有电梯,协助对接房东`

## 导入规则

1. 上传归属自动绑定当前登录用户
2. 上传前，当前用户名下所有 `待出租` 房源会先统一下架
3. 本次 Excel 中成功导入的房源会重新置为 `待出租`
4. 没出现在本次 Excel 中的原上架房源，会保持下架
5. 新导入房源会优先复用“同账号 + 同小区 + 同户室 + 同房间号”的历史图片

## 注意事项

- `楼盘名称` 必须能在系统小区表里匹配到
- `楼栋房间号` 不能为空
- `价格`、`返佣金额` 应填写整数
- 首行必须是表头
